# Alpha 0.6 PBR texture foundation
Generated 128×128 repeating grayscale albedo (sRGB), tangent-space normals (linear), and ORM packed maps (R=ambient occlusion 1, G=roughness, B=metalness). Presets: concrete, asphalt, stone, sand, weathered steel, polished steel, leather, fabric.
Surface targets are buildings, terrain, roads, robot bodies, and procedural player armor. Explicit natural-language edits or the mobile-accessible material selector change textures without rebuilding the scene, resetting quests, moving the player, or restarting Rapier physics. Changes are browser-local and stored separately from GameSpec v1 for backwards compatibility. Topology changes still rebuild.
Imported GLB characters keep their authored UV/material maps; no texturing overwrite of imported characters. Decode-time imported image limit 2048px per side, 8 megapixels aggregate (~32 MiB before mipmaps). Each generated map is 128px RGBA, 3 per preset, up to 1.5 MiB source data for all eight presets; browser GPU memory may be higher. Generated textures are procedural, not AI-created image textures. KTX2/Basis compression, custom painting, external image ingestion and true photorealistic generation are future work.
Acceptance: node:test regressions, real Three.js material smoke and Chrome/WebGL browser with quest/physics no-reset plus mobile controls. No Vercel deployment.
